Open-source developer tool

A pastebin built for the way developers work.

PasteDB is an open-source platform for sharing code, notes, text and images through simple links. It brings paste sharing together with developer tools, including end-to-end encrypted pastes, APIs, SDKs, a CLI and a Visual Studio Code extension.

01 / PLATFORM

More than a place to paste code.

PasteDB combines the familiar simplicity of a pastebin with features for privacy, organization and developer workflows. Use the web interface for quick sharing, or connect through the tools built around the platform.

01 — SHARE

Text, code and images

Create shareable pastes, use syntax highlighting for 40+ languages, preview Markdown and HTML, and share images through dedicated links.

02 — PRIVACY

End-to-end encrypted pastes

Paste content is encrypted on the client before it is uploaded. The encryption key is not stored on the PasteDB server. If all trusted devices and keys are lost, encrypted content cannot be recovered.

03 — CONTROL

Sharing controls

Choose public or private pastes, add password protection, set expiration times or use Burn After Read for supported one-time sharing.

04 — ORGANIZE

Dashboard and history

Manage your pastes, review analytics and access version history for supported logged-in pastes, with up to 10 historical versions.

05 — DISCOVER

Explore and share

Explore public pastes, create custom paste IDs, generate QR codes and use Link Paste to share small pieces of content stored in a compressed URL.

06 — UTILITIES

Useful in the browser

Copy content, render Markdown, preview HTML and run supported languages using PasteDB's built-in utilities.

03 / THE ECOSYSTEM

Part of the open-source pastebin landscape.

Open-source pastebin projects serve different needs. Some focus on minimal sharing, some emphasize secret sharing or encryption, and others provide broader developer workflows. PasteDB is one of the projects in this ecosystem.

Projects such as PrivateBin, Paaster, Yopass and Pastefy are also part of this space. They have their own designs, security models and priorities. PasteDB's focus is to combine paste sharing with an accompanying set of developer integrations. This is a description of project focus, not a security audit or a claim that one tool is universally better than another.

05 / QUESTIONS

Frequently asked questions.

What is PasteDB?

PasteDB is an open-source paste-sharing platform for creating and sharing code snippets, notes, text and images through links. It also provides developer tools such as an API, SDKs, a CLI and a VS Code extension.

Is PasteDB open source?

Yes. The main PasteDB repository is publicly available on GitHub under the MIT License: github.com/sorathiya903/pastedb.

Does PasteDB support end-to-end encryption?

PasteDB supports end-to-end encrypted pastes. Content is encrypted on the client before upload, and the encryption key is not stored on the PasteDB server. Keep your trusted devices and keys safe: encrypted content cannot be recovered if all copies of the key are lost.

Can I use PasteDB from a terminal or code editor?

Yes. PasteDB provides a CLI and a Visual Studio Code extension, as well as official Python and Node.js SDKs.

Does PasteDB have an API?

Yes. PasteDB provides API access and API key management for programmatic use. See the platform for current API documentation and access details.

What makes PasteDB different from other pastebins?

PasteDB combines common paste-sharing features with a set of developer integrations, including Python and Node.js SDKs, a terminal CLI and a VS Code extension. Other pastebin projects have different feature sets and priorities.

Who creates and maintains PasteDB?

PasteDB is independently created and maintained by Aditya Sorathiya. Its main source repository and related project links are available on GitHub.
